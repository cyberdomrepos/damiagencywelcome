# Archived component backups

This folder contains archived backups and original copies of components that were moved out of `app/components` to keep the main components directory clean.

- `MusicCarousel-backup.tsx` — original small backup copy.
- `MusicCarousel-original-backup.tsx` — full original source archived.

If you need to restore any file to `app/components`, copy it back and update imports as needed.

Note: pointer files in `app/components` were removed to avoid confusion.
